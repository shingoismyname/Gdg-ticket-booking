# GDG ticket booking system
- Project đặt vé sự kiện quy mô nhỏ (vai cốt)
## Công nghệ sử dụng
- **Frontend**: React, Vite, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: Supabase / PostgreSQL
- **API**: Frontend giao tiếp với backend thông qua HTTP API
## Yêu cầu trước khi chạy <br>
Cài đặt các công cụ sau trên máy:

- Node.js (LTS) và npm
- Git
- Visual Studio Code hoặc một trình soạn thảo code tương đương
##  Clone project về máy
```console
git clone <url của repo>
cd <folder của repo>
```
## Cấu hình Supabase
- Project sử dụng Supabase để kết nối database. Các thành viên cần liên hệ trực tiếp với người quản lý project để nhận cấu hình môi trường cần thiết.
## Cấu hình frontend, backend
- Nhận các biến môi trường và tên biến chính xác từ người quản lý project, sau đó điền giá trị tương ứng vào file `.env` và `.env.local`
## Cài đặt dependencies cho frontend và backend
VD <br>
```console
cd backend, ticket-booking
npm install
```
## Chạy local
- Vào ticket-booking và backend rồi: <br>
```console
npm run dev
```
